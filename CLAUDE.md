# Working rules

- Before giving the maintainer commands to run on their own machine, load the `bwn-field` skill (`.claude/skills/bwn-field/SKILL.md`) and rehearse every block as it says.
- Reproduce a reported problem in a matching field cell (docker or `field-adhoc`) before fixing it.
- Never assign the maintainer manual testing or release steps: no "run this and tell me", no workflow clicks, no npm logins or promotions.

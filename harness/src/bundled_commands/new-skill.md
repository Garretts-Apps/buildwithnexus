# New skill

Name: $ARGUMENTS

1. Create `skills/<name>/SKILL.md` with `name`, `description`, and When to use.
2. Keep the body under one screen. No employer or product-specific examples.
3. Add `scripts/` or `references/` only when the user asked for them.
4. Do not register in catalogs outside this tree unless asked.

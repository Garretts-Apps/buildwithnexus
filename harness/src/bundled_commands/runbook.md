# Runbook

Service: $ARGUMENTS

1. Document start, stop, health checks, and where logs live.
2. Add top failure modes with symptoms, checks, and safe mitigations.
3. Name escalation when mitigations fail. No secrets in the doc.
4. Prefer `docs/runbooks/` if the repo has a docs folder.

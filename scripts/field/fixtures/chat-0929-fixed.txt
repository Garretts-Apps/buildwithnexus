### U07: the one-paste setup script, without exec, ending in a check

bwn opens as its own step afterwards, so a failing step is the last thing on
screen and the shell is still there:
```bash
cat > ~/bwn-vision-setup.sh <<'EOF'
#!/usr/bin/env bash
set -euo pipefail
MODEL=gemma3:4b
sudo apt-get update -y
sudo apt-get install -y curl ca-certificates zstd imagemagick fonts-dejavu-core
command -v ollama >/dev/null || curl -fsSL https://ollama.com/install.sh | sh
curl -sf http://localhost:11434/api/version || { echo 'Ollama is not answering: start it with ollama serve'; exit 1; }
ollama pull "$MODEL"
ollama list
EOF
chmod +x ~/bwn-vision-setup.sh && ~/bwn-vision-setup.sh
```

```bash
cd /devsafe/vision-test && bwn --provider ollama --model gemma3:4b --prompt "Read @test.png and write every piece of text you can see in it, plus the shapes and colours, to image-notes.md"
```

### U25: winget where it exists, the release zip where it does not

```powershell
if (Get-Command winget -ErrorAction SilentlyContinue) {
  winget install --id Microsoft.WindowsTerminal -e --accept-source-agreements --accept-package-agreements
} else {
  $a = (Invoke-RestMethod https://api.github.com/repos/microsoft/terminal/releases/latest).assets | Where-Object name -like 'Microsoft.WindowsTerminal_*_x64.zip' | Select-Object -First 1
  Invoke-WebRequest -UseBasicParsing $a.browser_download_url -OutFile "$env:TEMP\wt.zip"
  Expand-Archive "$env:TEMP\wt.zip" C:\tools\wt -Force
}
(Get-Command wt.exe -ErrorAction SilentlyContinue).Source, (Get-ChildItem C:\tools\wt -Recurse -Filter wt.exe -ErrorAction SilentlyContinue).FullName
```

### U28: check for admin, wait for msiexec, read its exit code, refresh PATH

```powershell
$admin = ([Security.Principal.WindowsPrincipal][Security.Principal.WindowsIdentity]::GetCurrent()).IsInRole([Security.Principal.WindowsBuiltInRole]::Administrator)
if (-not $admin) { throw 'The Node MSI installs for all users: open PowerShell with Run as administrator.' }
$p = Start-Process msiexec.exe -ArgumentList '/i','C:\dev\installers\node.msi','/qn','/norestart' -Wait -PassThru
if ($p.ExitCode -notin 0, 3010) { throw "The Node MSI failed with exit code $($p.ExitCode)" }
$env:Path = [Environment]::GetEnvironmentVariable('Path','Machine') + ';' + [Environment]::GetEnvironmentVariable('Path','User')
node -v
```
